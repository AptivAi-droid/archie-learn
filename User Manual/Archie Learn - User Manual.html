1. What is Archie Learn?

Archie Learn is a mobile-first web app that gives every South African high-school learner their own patient, CAPS-aligned AI study partner — Archie. Archie never just hands over answers. He coaches learners to understand, using everyday South African examples (taxi fares, spaza shops, rands and cents), and celebrates every win.

What learners can do

  • Chat with Archie — a Socratic AI tutor for any subject.
  • Lessons — CAPS-aligned topic notes with worked examples.
  • Practice — exam-style questions marked instantly by AI.
  • Progress — streaks, session counts and a learning companion.

Who it’s for

  • Students (Grades 8–12) — the core experience.
  • Teachers — create classes and track learners.
  • Parents/Guardians — follow a child’s progress.
  • Admins — oversee usage, feedback and accounts.
About the pictures in this manual. The screen images are faithful renderings of the live app (same navy & gold design, same wording and layout). Once the database is switched on for the pilot, these can be replaced with live photo screenshots on request.

Signing up as a student

Two ways to create a student account:

  1. Continue with Google — one tap, sign up with a Google address. No password to remember.
  2. Email + password + date of birth — password must be at least 8 characters.

The date of birth sets the right experience:

  • Under 13: sign-up is not allowed (the app is for ages 13+).
  • 13–17: continues as a student.
  • 18+: redirected to the Teacher/Parent application.
If email confirmation is switched on, you’ll see a “Check your email” screen with a Resend button. For the pilot this is usually turned off so you can log in immediately.

4. Archie Chat (the AI tutor)

This is the heart of the app. Archie is a Socratic tutor:

  • He won’t answer until you’ve had a go first — he asks guiding questions.
  • Stuck after 2 tries? He gives a hint. After 3, he walks through it step by step.
  • He always says what you got right first, keeps replies short, and uses SA examples.
  • Celebrates wins: “Sharp sharp!”, “You’ve got it now.”

Switching subjects

Tap the subject name under the header to switch between your subjects at any time. Your choice is saved.

Demo mode (for showcases)

Triple-tap the “Archie Learn” wordmark in the chat header. A small dot (·) appears next to the name. In demo mode Archie replies with realistic, hand-crafted answers without using any AI credits — perfect for partner demos. Triple-tap again to turn it off.

Parent link. The chain-link icon in the chat header lets a learner generate a 6-character code to share with a parent (see the Parents section).

6. Practice (AI-marked questions)

Test yourself with exam-style questions that Archie marks instantly:

  1. Choose a subject and grade. You get a set of questions.
  2. Type your answer and tap Submit answer.
  3. Archie returns a score, specific feedback on what you got right and missed, and an encouraging note.
  4. At the end you see your percentage and a per-question breakdown.
Practice needs the question database to be switched on. Until then it shows “No practice questions available” — this unlocks once the project’s database setup is applied.

9. Parent / Guardian Guide

Parents also apply via “I’m a Teacher or Parent”. Once in, you link to your child’s account:

  1. Ask your child to open Archie and tap the chain-link icon in the chat header to generate a 6-character code.
  2. On your Parent Dashboard, type the code into Link a student account and tap Link.

Once linked you’ll see your child’s weekly sessions, questions answered, practice average and a short note from Archie.

10. Admin Guide

Admins sign in at /admin/login and land on a four-tab dashboard:

  • Overview — total users, sessions, average rating and recent feedback.
  • Feedback — all learner ratings, with CSV export.
  • Sessions — every chat session with expandable transcripts, CSV export.
  • Users — per-user roll-up (name, role, grade, subject, sessions, average rating), CSV export.
The admin dashboard reads only data that already exists, so it works even before the full database setup is applied.

12. Privacy & Safety

  • Ages 13+. Sign-up blocks under-13s; adults are routed to a separate vetted application.
  • POPIA-aware. Only the details needed to personalise learning are collected.
  • Archie coaches, he doesn’t cheat. He guides understanding rather than handing out answers.
  • Teacher/Parent vetting. Adult accounts are reviewed before they gain access to learner data.
When signing up with Google, the date-of-birth age check is being extended to the profile step — for now, restrict Google sign-up to the intended pilot users.

13. Troubleshooting & FAQ

“Could not load questions” on Practice / “Could not create class” for Teachers

The database setup hasn’t been applied yet. An administrator must run the project’s SQL setup once; then these features work immediately, with no app update needed.

I signed up but never received a confirmation email

For the pilot, email confirmation is usually turned off so you can log in straight away. If it’s on, check your spam folder or use the Resend confirmation email button. An admin can also confirm your account.

Archie replies “Eish, something went wrong” in chat

This means the AI service isn’t reachable (usually AI credits need topping up, or the live AI backend isn’t connected yet). Use demo mode (triple-tap the logo) for a credit-free walkthrough.

The “Continue with Google” button says it’s not available

The Google provider hasn’t been switched on in project settings yet. Use email + password until then.

How do I install the app on my phone?

Open the link in your browser, then use the browser menu → Add to Home Screen. Archie then opens like a normal app.

Demo mode for showcases

Triple-tap the “Archie Learn” wordmark in the chat header. Archie answers without using AI credits — ideal for partner demonstrations.
